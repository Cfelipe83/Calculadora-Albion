# 🗡️ Albion Expert Hub (Servidor América / West)

Una suite web avanzada, completamente reescrita en Vanilla JS y Tailwind CSS, para el cálculo y monitoreo de precios en tiempo real de **Albion Online**.
Configurada de forma estricta para trabajar exclusivamente con la API del **Servidor América (West)**.

## 🚀 Características
1. **Refinación (`index.html`):** RRR exactos por ciudad.
2. **Mercado en Vivo con Autocompletado (`mercado.html`):** Busca ítems en español. Autocompletado directo.
3. **Crafteo Expandido (`crafteo.html`):** Todos los árboles de crafteo de armas y armaduras.
4. **Buscador de Jugadores (`jugadores.html`):** Fama de Asesinatos/Muertes de jugadores en América.
5. **Islas (`islas.html`):** Ganadería, agricultura y huertos.

## 🛠️ Instalación en GitHub Pages
1. Extrae los archivos.
2. Súbelos a la rama `main` de tu repositorio.
3. Activa GitHub Pages en `Settings -> Pages`.
