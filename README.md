# 🗡️ Calculadora de Refinación e Islas - Albion Online

Calculadora interactiva en tiempo real para **Albion Online**, conectada directamente a los servidores del **Albion Online Data Project (AODP)** y con renderizado de iconos oficiales del juego.

---

## ✨ Características

- 📊 **Refinación en tiempo real:** Cálculo exacto considerando la Tasa de Retorno de Recursos (RRR), bonificación de ciudad y uso de Foco.
- 🌾 **Isla y Agricultura:** Cálculo de rendimiento diario, reposición de semillas regadas con Foco y ganancia neta.
- 🌐 **Soporte Multi-servidor:** Compatible con Europa (EU), América (West) y Asia (East).
- 🎨 **Iconos oficiales:** Renderizado dinámico desde el CDN oficial de Albion Online.
- ⚡ **100% Gratuito y Serverless:** Funciona directamente en el navegador sin costes de infraestructura.

---

## 🚀 Despliegue en GitHub Pages

1. Sube el archivo `index.html` a este repositorio.
2. Ve a **Settings** > **Pages**.
3. En **Branch**, selecciona `main` y la carpeta `/(root)`.
4. Guarda y en 1 minuto estará disponible en:
   `https://cfelipe83.github.io/Calculadora-Albion/`
